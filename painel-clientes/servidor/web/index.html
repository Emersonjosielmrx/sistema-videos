Nova campanha

Os números do anúncio (investido, alcance, cliques, resultados) estão no Gerenciador de Anúncios ou em "Ver insights" do post impulsionado. Ao salvar, a campanha ganha um link rastreado próprio: use ele no anúncio para saber quantas pessoas vieram dela.

Importar do Gerenciador de Anúncios

No Gerenciador de Anúncios: Campanhas → escolha o período → Exportar → "Exportar dados da tabela" (CSV). Escolha o arquivo aqui. Campanha que já existe (mesmo nome) tem os números atualizados.

Novo link rastreado

Cada clique é contado antes de levar a pessoa para o destino. Use um link diferente em cada lugar (bio, story, anúncio, panfleto com QR code) para saber de onde vêm os contatos.
