## Resposta da IA

Analisando o código, encontrei a **causa raiz** do problema:

## 1. CAUSA

**Arquivo:** `bin\tiktok_cdp_poster.py:217-230`

O problema está na lógica de clique e confirmação:

```python
# linha 217: só tenta clicar se botão estiver "on"
if estado_final == 'on':
    result = evaluate(...click...)
    if result:
        posted = True  # linha 220
```

**Mas:** a variável `posted` só indica que o JavaScript retornou `true` ao tentar clicar. **Não significa que o TikTok realmente publicou.**

A sonda de confirmação (linhas 243-257) roda **sempre, independente de `posted`**:
```python
for i in range(45):  # linha 243 - roda mesmo se posted=False
    time.sleep(2)
    st = evaluate(browser_ws, sonda, session_id) or {}
    if st.get('ok') or '/upload' not in st.get('url'):
        confirmado = True
        break
```

**O problema real:** A sonda busca textos como "foi publicad", "video posted", "has been posted" no `document.body.innerText` (linha 240), mas:

1. **Se o TikTok mostrar a confirmação em uma notificação toast que desaparece rapidamente** (antes dos 2s entre checagens), a sonda perde.
2. **Se o TikTok redirecionar para `/content` ou outra URL sem mostrar texto de confirmação**, a sonda só detecta pela saída do `/upload`, mas pode ter timeout antes.
3. **Se o upload do vídeo demorar e o TikTok não mostrar "uploading" em inglês/português**, a sonda não detecta progresso.

**Evidência no log (linha 50, 59, 65, 132, 134):**
```
CLICOU SEM CONFIRMAR: video.mp4 anotado como postado (não reposta)
ERRO: NAO CONFIRMADO: TikTok nao mostrou publicado
```

Isso prova que:
- O clique funcionou (`posted=True` na linha 220/226)
- Mas a sonda rodou por 90s (45 iterações × 2s) sem detectar confirmação
- O vídeo **pode ter sido postado** (por isso não reposta), mas a sonda não viu

## 2. PLANO

**Mudanças mínimas:**

1. **Aumentar o timeout da sonda** de 45 para 60 iterações (90s → 120s), porque upload pode demorar.

2. **Melhorar a detecção de saída do /upload**: Em vez de só checar `'/upload' not in url`, verificar se chegou em página válida de sucesso (`/content`, `/creator-center`, ou qualquer URL que não seja `/upload` nem erro).

3. **Adicionar log de debug**: Imprimir o `innerText` parcial quando não detectar nada, para o dono ver o que o TikTok realmente mostrou.

**Arquivo a mudar:** `bin\tiktok_cdp_poster.py`
