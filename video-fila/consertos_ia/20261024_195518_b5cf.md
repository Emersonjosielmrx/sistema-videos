## 1. CAUSA

A tarefa **PostadorDeVideos** está configurada com **`StopIfGoingOnBatteries: True`** (linha "Gerenciamento de Energia: Parar se estiver usando baterias"). 

O código de erro **0x40010004 (decimal: 1073807364)** que aparece em:
- Task Scheduler: "Último resultado: 1073807364" 
- Log anterior (linha 3 do postar_auto.log): `[07/08/2026  9:37:35,65] Fim (exit code 1073807364)`

Este é **exatamente o mesmo código** do caso resolvido **2026-10-24 13:48** (TikTokRodadaExtra) que documentou: **"0x8007042B significa 'O processo foi finalizado de forma inesperada' e é o código específico que o Windows Task Scheduler retorna quando interrompe uma tarefa porque o PC mudou para alimentação por bateria"**.

**Prova:**
- Tarefa começou: 24/10/2026 06:40:01
- Última linha do log: `[24/10/2026  6:53:17,17] Inicio TikTok` (13 minutos depois)
- Sem linha de "FIM CICLO COMPLETO" = tarefa foi **interrompida pelo Windows**
- O PC tem bateria (notebook confirmado nos casos anteriores via WMI)

## 2. PLANO

**Arquivo:** Configuração da tarefa agendada `PostadorDeVideos` (via `schtasks`)

**O que sai:**
```
Gerenciamento de Energia: Parar se estiver usando baterias, Não iniciar se estiver usando baterias
```

**O que entra:**
```
Gerenciamento de Energia: (sem restrições de bateria)
```

**Comando a rodar:**
```batch
schtasks /Change /TN "PostadorDeVideos" /RL HIGHEST /IT
```

Depois conferir:
```batch
schtasks /Query /TN "PostadorDeVideos" /FO LIST /V | findstr "Gerenciamento"
```

## 3. RISCO

**Baixo.** A mudança só remove a restrição de energia que está travando a tarefa. 

**Como desfazer:** 
```batch
schtasks /Change /TN "PostadorDeVideos" /IT /RL HIGHEST
```
(Nota: não há flag direta pra re-ativar a restrição de bateria pelo `/Change`; seria necessário recriar a tarefa ou editar via GUI do Task Scheduler se precisar voltar)
