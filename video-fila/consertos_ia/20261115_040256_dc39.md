## 1. CAUSA

**Timeout do Whisper estourou porque o cálculo usa `duração + 60s` em vez da duração real:**

**Prova (anime_auto.py:280):**
```python
txt, lang = anime_fetch.transcribe_whisper(video, max_seconds=int(anime_probe.video_duration(str(video)) or 1440) + 60)
```

**Prova (log linha onde erro apareceu, 03:52:18):**
- Vídeo: Faiih3MIBTo (duração real: **177.45s** = 2min 57s)
- `max_seconds` passado: `int(177.45) + 60` = **237s**
- Timeout calculado: `max(900, 237 * 5)` = **1185s** ✓ (confere com o log!)
- Whisper travou/ficou lento e bateu nos 1185s

**Para vídeos curtos, a lógica está ERRADA:**
- Comentário diz "mínimo 900s" mas o código ignora a duração real
- Vídeo de 3 min (177s) + margem (60s) = 237s, multiplicado por 5 = **1185s timeout** (quase 20 min pra transcrever 3 min de áudio!)
- O mínimo de 900s deveria ter sido aplicado **antes** de multiplicar por 5

**Timeout do ffmpeg de cobertura:**
- Prova (parceiro_marca.py:372): `subprocess.run([...ffmpeg...], timeout=60)`
- Hardcoded 60s pra extrair 1 frame em shorts — CPU carregada trava e dá timeout

---

## 2. PLANO

**A) Whisper timeout (anime_fetch.py:445-446):**

**Sai:**
```python
if max_seconds <= 600:
    whisper_timeout = max(900, int(max_seconds * 5))
```

**Entra:**
```python
if max_seconds <= 600:
    # Calcula sobre a duração REAL do vídeo (sem a margem de +60s), mínimo 900s
    duracao_real = max(60, max_seconds - 60)  # remove os +60s que anime_auto.py adiciona
    whisper_timeout = max(900, int(duracao_real * 5))
```

**B) ffmpeg cobertura timeout (parceiro_marca.py:372, 428):**

**Sai (2 lugares):**
```python
timeout=60
```

**Entra:**
```python
timeout=180  # CPU carregada + I/O lento em shorts precisa mais margem
```

**Conferir depois:**
- Rodar `tail -f workspace/anime/_parceiro_*.log` e ver se shorts passam sem timeout
- Se Whisper de vídeo curto terminar antes de 900s, a mudança funcionou

---

## 3. RISCO

**Whisper:**
- Vídeos de 1-3 min que antes tinham 900-1500s de timeout agora terão **900s fixo** (mínimo respeitado)
- Se um vídeo curto realmente precisar de 15+ min de Whisper (CPU travada), ainda vai dar timeout — **mas isso é um sintoma de problema maior (CPU sobrecarregada)**
- Desfazer: voltar linha 446 pro `max(900, int(max_seconds * 5))`

**ffmpeg:**
- 180s ainda pode ser pouco se disco estiver muito lento ou I/O travado
- Desfazer: voltar `timeout=60` nas linhas 372 e 428 do parceiro_marca.py
