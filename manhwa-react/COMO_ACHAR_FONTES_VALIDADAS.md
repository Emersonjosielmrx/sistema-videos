# Como achar fontes validadas para react (método manual)

**Problema:** Buscar "canais de finanças faceless" retorna canais mortos, sem inscritos, sem views.

**Solução:** Inverter a lógica — partir de VÍDEOS que já bombaram, não de canais aleatórios.

---

## Método passo a passo (para cada nicho)

### 1. Vá direto no YouTube e busque por tema + "shorts"

Exemplos de busca:
- `educação financeira shorts`
- `história de terror animada`
- `resumo de anime shorts`
- `história de superação`
- `curiosidades inventos`

### 2. Filtre por views e data recente

No YouTube:
1. Digite a busca
2. Clique em **Filtros**
3. Selecione:
   - **Tipo:** Vídeo
   - **Data de upload:** Este mês ou Esta semana
   - **Ordenar por:** Contagem de visualizações

### 3. Abra os vídeos com 50k+ views

Critérios de validação ao assistir:
- ✅ **Faceless:** Dono NÃO aparece (só narração, animação, ou filmagem de objeto/ambiente)
- ✅ **Em português brasileiro**
- ✅ **Reagível:** Tem conteúdo visual interessante, não é só texto na tela
- ✅ **Sem copyright pesado:** Não é clipe de música, filme completo, ou conteúdo protegido

### 4. Anote o CANAL do vídeo que passou no teste

Formato para anotar:
```
NICHO: Finanças
VÍDEO QUE PERFORMOU: https://youtube.com/watch?v=XXXXX (150k views)
CANAL FONTE: @NomeDoCanal
POR QUE FUNCIONOU: Animação simples explicando juros compostos, narração clara
```

### 5. Assista 3-5 vídeos DESSE canal específico

Confirme que:
- Padrão de qualidade se mantém
- Frequência de postagem é boa (mínimo 1x por semana)
- Views consistentes (não foi só 1 viral)

## Locais para buscar por nicho

### Finanças (DicasFinanceirasDaIA + AssistIA Investimentos)
```
Buscar: "educação financeira shorts", "investimentos para iniciantes", "como economizar dinheiro"
Ideal: Animações explicativas, infográficos, simulações
```

### Terror/Mistério (Fio da Meada + MundoQueNaoExiste)
```
Buscar: "história de terror animada", "caso de mistério real", "enigmas não resolvidos"
Ideal: Narração + animação, histórias curtas, clima de suspense
```

### Histórias/Drama (HistoriasEmFrames)
```
Buscar: "história de superação", "história real emocionante", "relato animado"
Ideal: Narração emotiva + imagens/animação, histórias de 1-3 min
```

### Anime (ManhwaReact + Animescomia + canais Inovare)
```
Buscar: "resumo de anime shorts", "explicação de anime", "cena épica anime"
Ideal: Recap rápido, cena comentada, explicação de poder/habilidade
```

### Filmes/Séries (CenaReact)
```
Buscar: "cena de filme explicada", "curiosidades de série", "resumo de filme"
Ideal: Análise de cena, easter eggs, recap
```

### Inventos/Curiosidades (InventoReact)
```
Buscar: "invenções incríveis", "gadgets úteis", "experimentos científicos"
Ideal: Demonstração visual, sem pessoa na frente
```

### Games (CartuchoReact)
```
Buscar: "curiosidades de jogos retro", "easter eggs games", "história de console"
Ideal: Gameplay + narração, sem webcam
```

### Forja/Ofícios (ForjaReact)
```
Buscar: "forjando faca", "restauração de ferramenta", "carpintaria"
Ideal: Foco nas mãos e objeto, sem rosto
```

## O que fazer DEPOIS de achar 3-5 canais validados por nicho

1. **Documente aqui mesmo** (substitua a lista de canais mortos)
2. **Teste fazendo react de 1 vídeo** de cada canal encontrado
3. **Compare performance** depois de 48h
4. **Dobre a aposta** nos canais cujos reacts tiveram melhor engajamento

---

## Métricas para considerar um canal fonte BOM

- Vídeos com 50k+ views consistentemente
- Postagem regular (mínimo 1x/semana)
- Comentários ativos (engajamento real, não bots)
- Não tem strike de copyright
- Estilo visual reagível (não é só texto estático)

---

## Por que não usar listas prontas de "canais faceless"?

Porque:
1. A maioria está morta ou tem views baixas
2. O algoritmo muda rápido — o que funcionou 6 meses atrás pode estar saturado
3. **Validação manual é a única forma de garantir que o conteúdo é reagível**

---

**RESUMO:** Não busque canais. Busque vídeos que JÁ performaram, depois vá atrás do canal.
