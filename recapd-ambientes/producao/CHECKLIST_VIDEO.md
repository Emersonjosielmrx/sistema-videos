# CHECKLIST DE ANÁLISE DE VÍDEO

## 🔊 ÁUDIO
- [ ] Áudio sincronizado com as imagens (falas batem com os painéis certos)
- [ ] Legendas sincronizadas com a narração
- [ ] Vozes dos personagens combinam (masculino/feminino correto)
- [ ] Narração faz sentido com o que aparece na tela
- [ ] Sem robótica/travada (edge-tts fluindo natural)
- [ ] Sem palavras em inglês mal pronunciadas (portuguesify)

## 🎵 TRILHA SONORA
- [ ] Trilha presente (audível, não sumiu)
- [ ] Volume adequado (não alta demais, não inaudível)
- [ ] Troca conforme clima (tensa em tensão, leve em calma, etc.)
- [ ] Não é só uma trilha o vídeo todo
- [ ] Trilha combina com o momento (não trilha de jogo em cena romântica)
- [ ] Ducking funciona (abaixa quando narração fala, sobe no silêncio)

## 🎬 TRANSIÇÕES / EFEITOS VISUAIS
- [ ] Tem transição entre painéis (fade, wipe, dissolve — não corte bruto)
- [ ] SFX audíveis nas transições (whoosh, impacto, etc.)
- [ ] Efeito de shake em cenas de impacto
- [ ] Sem vinheta/luneta escurecendo os cantos (esconde balões)

## 🎭 MEMES
- [ ] Memes aparecem (a cada ~7 clips)
- [ ] Memes TÊM SOM (SFX de comédia junto)
- [ ] Memes NÃO aparecem em cena triste/tensa
- [ ] Trilha NÃO corta durante meme
- [ ] Meme tem duração adequada (~3s)

## 📐 PAINÉIS / IMAGENS
- [ ] Todos os painéis estão presentes (nenhum pulado)
- [ ] Os 2 primeiros painéis (capa/restaurante) aparecem
- [ ] Painéis na ordem correta
- [ ] Sem painéis em branco
- [ ] Movimento Ken Burns suave (pan/zoom)

## 📝 LEGENDAS
- [ ] Legendas visíveis (não cortadas/escondidas)
- [ ] Karaokê funciona (palavra por palavra)
- [ ] Watermark do canal presente
- [ ] Texto legível (não muito pequeno)

## 📏 QUALIDADE TÉCNICA
- [ ] Resolução 1080x1920 (vertical)
- [ ] Sem tela preta entre clips
- [ ] Vídeo abre sem erro
- [ ] Tamanho razoável (200-400MB pra cap completo)
- [ ] Duração compatível (~6-8 min pra 108 painéis)
