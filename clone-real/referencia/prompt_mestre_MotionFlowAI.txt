PROMPT PARA CRIAR O MOTIONFLOW AI


========================================================
OBJETIVO DA FERRAMENTA
========================================================


Crie uma ferramenta profissional dentro do Google Flow chamada “MotionFlow AI”.


A ferramenta deve permitir trabalhar com duas funções principais:


1. ROTEIRO → GERAÇÃO DE CENAS
2. MOTION SYNC → TRANSFERÊNCIA DE MOVIMENTO


A ferramenta deve ser simples o suficiente para iniciantes, mas ter uma aparência profissional e recursos avançados.


IMPORTANTE:


Utilize prioritariamente os recursos, modelos e capacidades NATIVAS disponíveis dentro do Google Flow.


Não crie funcionalidades fictícias.


Sempre que uma capacidade não estiver disponível no modelo selecionado, utilize a melhor alternativa nativa disponível e informe corretamente a limitação.


Não crie apenas botões decorativos.


Todos os botões, uploads, seletores, previews, gerações e downloads devem estar funcionalmente conectados sempre que o Google Flow disponibilizar essa capacidade.

========================================================
FUNCIONAMENTO DO GERADOR DE CENAS
========================================================


Quando o usuário clicar em “Gerar Cenas”, a ferramenta deve analisar o roteiro e dividi-lo automaticamente em cenas visualmente coerentes.


Não dividir o roteiro de maneira aleatória.


Analise:
contexto,
tema,
emoção,
mudanças de assunto,
ritmo da narração
e intenção de cada trecho.


Para cada cena criada, mostrar um CARD individual contendo:


Número da cena


Trecho correspondente do roteiro


Descrição visual


Prompt para geração da imagem


Prompt para animação da imagem


Movimento de câmera sugerido

========================================================
INTELIGÊNCIA DAS CENAS
========================================================


Não criar imagens genéricas.


Cada cena deve representar visualmente o significado exato do trecho da narração.


A ferramenta também deve interpretar a emoção do texto.


Exemplos:


Se o trecho representar dúvida:
a imagem e a animação devem transmitir dúvida.


Se representar tensão:
iluminação, câmera e movimento devem transmitir tensão.


Se representar descoberta:
a cena deve transmitir descoberta.


Se representar curiosidade:
não revelar visualmente a resposta antes da narração.


Se representar autoridade:
usar composição visual mais sólida.


Se representar entusiasmo:
usar movimento mais energético.


A animação deve acompanhar o significado emocional da narração, e não apenas movimentar elementos aleatoriamente.


========================================================
ABA 2 — MOTION SYNC
========================================================


Crie uma segunda aba chamada:


MOTION SYNC


Objetivo:


Permitir que o usuário envie uma imagem de uma pessoa e um vídeo base para fazer a pessoa da imagem repetir os movimentos do vídeo.


========================================================
ENTRADA 1
========================================================


Criar um campo de upload chamado:


IMAGEM PRINCIPAL — APARÊNCIA BLOQUEADA


Descrição abaixo:


“Esta imagem define a identidade, aparência, roupa e cenário do resultado final.”


Permitir:


arrastar e soltar


selecionar arquivo


selecionar mídia já existente na galeria do Flow, quando disponível


Mostrar preview da imagem.


========================================================
ENTRADA 2
========================================================


Criar um segundo campo chamado:


VÍDEO BASE — USAR SOMENTE MOVIMENTOS


Descrição:


“Este vídeo será utilizado exclusivamente como referência de movimento.”


Permitir:


upload


drag and drop


seleção da galeria


preview do vídeo.


========================================================
CAMPO DE PROMPT
========================================================


Logo abaixo das duas referências, adicionar um campo grande chamado:


PROMPT / INSTRUÇÕES ADICIONAIS


Placeholder:


“Ex.: preservar rosto, cabelo, roupa e cenário. Copiar somente os movimentos do vídeo base...”


O conteúdo escrito nesse campo DEVE ser enviado junto com a imagem e o vídeo para o modelo de geração.


Não criar o campo apenas visualmente.


========================================================
LÓGICA PRINCIPAL DO MOTION SYNC
========================================================


A IMAGEM PRINCIPAL deve ser considerada a fonte visual absoluta e prioritária.


O VÍDEO BASE deve ser utilizado exclusivamente como referência de movimento.


A ferramenta deve preservar com máxima fidelidade possível da imagem principal:

cores


estética geral


Não recriar a pessoa.


Não reinterpretar a identidade.


Não trocar o rosto.


Não trocar cabelo.


Não alterar roupa.


Não alterar cenário.


Não utilizar aparência visual do vídeo base.


========================================================

========================================================
REGRA DE PRIORIDADE
========================================================


PRIORIDADE 1:


Preservação da imagem principal.


PRIORIDADE 2:


Transferência do movimento do vídeo base.


Caso exista qualquer conflito entre manter a aparência da imagem e reproduzir um movimento:


PRESERVE A APARÊNCIA DA IMAGEM.


O vídeo final deve parecer que:


A PESSOA DA IMAGEM ORIGINAL SIMPLESMENTE COMEÇOU A REALIZAR OS MOVIMENTOS DO VÍDEO BASE.


========================================================
FIDELIDADE MÁXIMA AO MOVIMENTO
========================================================


Não quero apenas movimento parecido.


Quero a maior fidelidade temporal e corporal tecnicamente possível ao vídeo base.


Não estilizar os movimentos.


Não suavizar desnecessariamente.


Não inventar novos movimentos.


Não adicionar gestos.


Não modificar a ordem dos movimentos.


Não modificar o timing.


Não acelerar.


Não desacelerar.


Não substituir os gestos por movimentos semelhantes.


Não criar movimentos genéricos de avatar.


Não exagerar expressões.


Não criar movimentos extras de cabeça.


Não criar balanços corporais artificiais.


Se o modelo disponibilizar parâmetros equivalentes, utilizar:


motion fidelity = maximum


motion strength = high


source motion adherence = strict


temporal consistency = maximum


preserve source timing = enabled


creativity = minimum


stylization = minimum


motion smoothing = minimum ou disabled


camera reinterpretation = disabled


identity preservation = maximum


reference image strength = maximum


Utilize essas configurações somente se forem realmente suportadas pelo modelo.


Não invente parâmetros inexistentes.


========================================================
PROMPT INTERNO PADRÃO DO MOTION SYNC
========================================================


Toda geração Motion Sync deve utilizar internamente uma instrução equivalente a:


“Use a imagem principal como fonte visual absoluta.


Preserve integralmente rosto, identidade, cabelo, corpo, proporções, pele, roupa, acessórios, cenário, iluminação e estética.


Use o vídeo base exclusivamente como fonte de movimento.


Reproduza com máxima fidelidade possível os mesmos gestos, postura, movimentos corporais, movimento das mãos, braços e cabeça, ritmo, timing, velocidade, pausas e sequência temporal do vídeo base.


Não copie aparência, pessoa, rosto, cabelo, roupa, cenário ou iluminação do vídeo base.


Não estilize, não reinvente e não adicione movimentos.


Se houver conflito entre aparência e movimento, preserve a imagem principal.”
