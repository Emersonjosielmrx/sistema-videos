# sistema-videos

Cópia só do CÓDIGO dos projetos de vídeo (recap de anime/manhwa, Shorts, longos, capas, postagem no YouTube/TikTok/Instagram, Flow/Veo, Kaggle).
Mídia, modelos, perfis de navegador, logs e segredos ficam fora. Chave/senha dentro de código aparece como `<SEGREDO_REMOVIDO>`.

Cada pasta da raiz = um projeto do disco D: da máquina principal. Atualizado sozinho todo dia (`hipercool-materiais/comum/salvar_github.py`).

Comece por:
- `recapd-ambientes/` — recap longo (Kaggle), Shorts de parceiro, capas (`producao/colab`, `producao/bin`)
- `video-fila/` — controlador das máquinas, painel, vigilância, relatório (`relatorio_ronda.py`)
- `postador-de-videos/` — postagem e Studio do YouTube, TikTok, Instagram
- `hipercool-materiais/comum/` — código comum e o pesquisador de melhorias
